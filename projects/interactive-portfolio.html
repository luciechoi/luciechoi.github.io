Overview

A minimalist personal portfolio website built from the ground up using Three.js and Vite, hosted on GitHub Pages. The design merges a clean, editorial white aesthetic with dynamic 3D interactive graphics, allowing visitors to engage with subtle visual depth without sacrificing content readability or load performance.

Key Features

  • Real-time 3D Scene: Procedural wireframe icosahedron and torus knot geometry with soft diffuse lighting and 200+ floating ambient particles.
  • Mouse & Cursor Parallax: Smooth lerp-interpolated camera rotations that respond dynamically to mouse movement.
  • Client-Side Tab Architecture: Fast, zero-reload tab switching with full browser history and direct hash routing support.
  • Automated CI/CD: GitHub Actions pipeline that builds and deploys the optimized Vite production bundle on every push.

Technical Stack & Architecture

The architecture separates presentation into a background WebGL layer and a responsive semantic DOM layer. By capping device pixel ratios and utilizing efficient requestAnimationFrame rendering loops, the site maintains a steady 60 FPS across both desktop and mobile devices.
