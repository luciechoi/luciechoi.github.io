Real-time raymarched volumetric cloud layer with Beer-Lambert extinction and Henyey-Greenstein phase scattering.

Overview

A real-time volumetric atmosphere and cloud simulation shader. Utilizing signed distance fields and 3D tiling noise textures (Perlin-Worley), the renderer casts primary camera rays and secondary light transmittance rays through participating media in screen space.

Technical Highlights

  • Dual-Phase Scattering: Henyey-Greenstein phase function modeling forward silver-lining highlights and diffuse ambient bounce.
  • Temporal Upsampling: Quarter-resolution raymarching with temporal reconstruction and depth-aware reprojection.
  • Precomputed Sky LUTs: Bruneton-style atmospheric look-up tables for single and multiple Rayleigh/Mie scattering.
