Unbiased global illumination render with dielectric glass transmission, caustics, and microfacet reflection.

Overview

A pure C++ physically based spectral path tracer implementing the rendering equation via numerical Monte Carlo integration. The renderer supports arbitrary triangular meshes, microfacet materials, refractive dielectrics, and environment lighting.

Key Features

  • Surface Area Heuristic (SAH) BVH: High-speed ray-primitive intersection using binned SAH BVH trees.
  • Multiple Importance Sampling (MIS): Balanced heuristic combining light source sampling and BSDF cosine sampling.
  • Fresnel Microfacet Models: GGX normal distribution with Smith geometric shadowing for realistic metals and plastics.
